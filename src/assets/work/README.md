# Field photos

Drop RobustWorx site photos here, then add a matching entry in
`src/data/workRecords.ts` to publish them on `/work`.

- Use the original camera file. Astro generates the responsive, compressed
  WebP variants at build time — do not pre-shrink or upscale.
- Landscape works best; portrait photos are cropped to the card ratio.
- Only genuine RobustWorx photos. No stock imagery.
